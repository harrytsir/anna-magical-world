# Ο Μαγικός Κόσμος της Άννας

Η δημόσια έκδοση της εγκυκλοπαίδειας για τις Ιστορίες της Άννας.

- `public/`: το site (σελίδα, δεδομένα σε JSON, εικόνες). Το Netlify δημοσιεύει αυτόν τον φάκελο.
- `tools/build.py`: το script που παράγει το `public/` από το εργαστήριο στο Claude.

Το περιεχόμενο γράφεται και διορθώνεται στο εργαστήριο μέσα στο Claude. Κάθε ανανέωση εδώ ανεβαίνει αυτόματα στο site μέσω Netlify.
